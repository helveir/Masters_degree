# Система управления давлением (Дипломный проект)

## Описание
Устройство для точного контроля давления воздуха в медицинских целях (гайморовые пазухи).  
Разработано на базе Arduino Nano.

## Аппаратная часть
- **Контроллер:** Arduino Nano (ATmega328P)
- **Датчик давления:** Аналоговый (0-5V)
- **Исполнительные механизмы:** 2 электромагнитных клапана (подача/отсос)
- **Интерфейс:** OLED 128x64 (I2C), RGB-индикация, кнопки, зуммер

## Пины подключения
| Компонент | Пины |
|-----------|------|
| Зуммер | D3 |
| RGB (R/G/B) | D2, D7, D8 |
| Кнопки (уменьш/старт/увелич) | D6, D9, D10 |
| Реле (подача/отсос) | D12, D11 |
| OLED I2C | A4(SDA), A5(SCL) |

## Установка и запуск
1. Установите библиотеки через Arduino IDE Library Manager:
   - Adafruit GFX Library
   - Adafruit SSD1306
2. Скопируйте все файлы в одну папку
3. Откройте Diplom.ino в Arduino IDE
4. Загрузите на Arduino Nano

## Структура проекта
- `Masters_degree.ino` - основной скетч с тестами и логикой
- `config.h` - определение всех пинов и констант
- `Buzzer.h/cpp` - модуль управления зуммером
- `RGB_LED.h/cpp` - модуль управления RGB светодиодом
- `Buttons.h/cpp` - модуль обработки кнопок (антидребезг, автоповтор)
- `Relay.h/cpp` - модуль управления реле
