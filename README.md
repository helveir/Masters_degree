# Система управления давлением

## Описание
Проект для Arduino Nano с интерфейсом управления давлением и подготовленной архитектурой под переход от стендового режима к рабочей логике.

Сейчас проект уже не сводится к одному тестовому `loop()`: базовые драйверы вынесены отдельно, а управляющая логика разложена по модулям состояний, контроля и безопасности.

## Аппаратная часть
- Контроллер: Arduino Nano (ATmega328P)
- Дисплей: OLED 128x64 по I2C
- Интерфейс: 3 кнопки, RGB-светодиод, зуммер
- Исполнительные механизмы: 2 реле (подача / отсос)
- Датчик давления: предусмотрен, сейчас может работать через симуляцию

## Подключение
| Компонент | Пины |
|-----------|------|
| Зуммер | D3 |
| RGB (R/G/B) | D2, D7, D8 |
| Кнопки (уменьшить / старт / увеличить) | D6, D9, D10 |
| Реле (подача / отсос) | D12, D11 |
| OLED I2C | A4 (SDA), A5 (SCL) |
| Датчик давления | A0 |

Все основные пины и параметры находятся в [include/config.h](/C:/Users/Hel/Documents/Arduino/Masters_degree/include/config.h).

## Текущее поведение
Сейчас система поддерживает такие состояния:
- `Idle`
- `Running`
- `Holding`
- `Completed`
- `Alarm`

Рабочий цикл пока может использовать симуляцию давления. Это нужно, чтобы развивать управляющую архитектуру до подключения реального датчика и насоса.

## Сборка
Проект настроен под PlatformIO.

### Основная прошивка
Используется окружение `nanoatmega328new` из [platformio.ini](/C:/Users/Hel/Documents/Arduino/Masters_degree/platformio.ini).

Нужные библиотеки:
- Adafruit GFX Library
- Adafruit SSD1306

### Тесты
Добавлено отдельное окружение `native` для проверки чистой логики без Arduino-железа.

Покрыты базовые сценарии:
- включение подачи при давлении ниже уставки
- включение отсоса при давлении выше уставки
- завершение удержания по таймеру
- срабатывание fault по таймауту регулирования

Тесты лежат в [test/test_logic/test_main.cpp](/C:/Users/Hel/Documents/Arduino/Masters_degree/test/test_logic/test_main.cpp).
