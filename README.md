# Система управления давлением

## Описание
Проект для Arduino Nano с управлением давлением, OLED-интерфейсом, клапанами и мотором через `L298N`.

Текущая версия уже работает не как тестовый монолитный скетч, а как разложенная по модулям программа:
- входы
- исполнительные устройства
- логика цикла
- проверки безопасности

Сейчас логика рассчитана на один полный цикл:
1. старт
2. накачка до `+границы`
3. переключение
4. отсос до `-границы`
5. возврат к `0 кПа`
6. завершение цикла

## Аппаратная часть
- Контроллер: Arduino Nano (ATmega328P)
- Дисплей: OLED 128x64 по I2C
- Интерфейс: 3 кнопки, RGB-светодиод, зуммер
- Исполнительные механизмы:
  - 2 реле клапанов
  - мотор через `L298N`
- Датчик давления:
  - вход `A1`
  - диапазон `-100..100 кПа`
  - выход `1..5 В`

## Текущее поведение
После включения программа:
- инициализирует дисплей, кнопки, RGB, зуммер, клапаны, мотор и датчик
- проверяет валидность первого чтения датчика
- если датчик читается нормально, переходит в `Idle`
- если датчик невалиден, уходит в `Alarm`

По умолчанию размах давления стоит `+/- 5 кПа`.

Кнопками `+` и `-` в состоянии ожидания можно менять этот размах.  
То есть задаётся не одна уставка, а симметричная граница вокруг нуля:
- `+X кПа`
- `-X кПа`

После нажатия `START` система выполняет один цикл:
- накачка до `+X`
- отсос до `-X`
- возврат к `0`
- завершение

Текущие состояния:
- `Idle`
- `Pressurizing`
- `Depressurizing`
- `ReturningToZero`
- `Completed`
- `Alarm`

На дисплее это отображается как:
- `IDLE`
- `PUMP`
- `SUCT`
- `ZERO`
- `DONE`
- `ALARM`
